# SANCHAR demo video: narration script

About 3 minutes (2:57), 495 spoken words, 10 scenes. Generated by `docs/video/build_video.py` from `docs/video/scenes.py`; every number is read from `bench/results/`.

## How to record your own voice

1. Record one clip per scene and save it as `docs/video/voice/scene01.m4a` … `scene10.m4a`. Windows Sound Recorder works; `.mp3`, `.wav` and `.ogg` are also fine.
2. Leave about half a second of silence at the start and end of each clip, and a short breath between sentences. Retake a scene whenever you like; only that clip changes.
3. Where a scene says **(pause)**, pause for about two seconds. The video fast-forwards during it.
4. Run `python docs/video/build_video.py --voice mine --team-name "…" --team-id "…"`. Each scene stretches to your pace and the captions follow your sentences. Any scene you have not recorded keeps the AI voice.

Keywords are in **bold**. They are highlighted in the captions, so say them clearly.

## What the technical terms mean (for questions)

- **Discrete-time kinematic model**: robots move at 1 m/s on a roadmap of 1 m cells, one cell per 1 s tick. Planning and the safety rule reason about which cell each robot occupies at each tick.
- **Windowed space-time A\***: each robot searches over (cell, time) pairs a few seconds ahead, treating higher-priority robots' broadcast plans as moving obstacles.
- **Guided-PIBT**: every tick, each robot picks its next cell in priority order, guided by its A\* path. A robot in the way inherits the pusher's priority and moves aside (priority inheritance with backtracking). This is the algorithm family that won the 2023 League of Robot Runners, made fully decentralized here.
- **Claim round and move round**: a robot first broadcasts which cell it wants, then moves only if the safety rule holds.
- **Reach set**: every cell a robot we have not heard from recently could have reached; we never enter it.
- **CRDT task board**: order records merge the same way on every robot in any order, so two robots never both keep one order.

## If a judge asks about kinematics

Say it plainly: the coordinator uses a discrete-time kinematic model (1 m/s, one roadmap node per tick). A continuous execution layer with velocity and acceleration limits for differential-drive robots and circular footprints sits underneath without changing the coordinator. It is the first Grand Finale item, and each robot's own safety scanner remains the physical backstop, as on every commercial AMR.
